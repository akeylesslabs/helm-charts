Akeyless Zero Trust Web Access, legacy registry credentials
===========================================================

"image.dockerRepositoryCreds" is deprecated and will be removed in a future chart version.
Create a kubernetes.io/dockerconfigjson Secret in the release namespace, and set
image.imagePullSecrets to it, for example [ { name: your-secret } ].
{{- end }}

Akeyless Zero Trust Web Access, IPv6 and dual-stack
===================================================

- IPv6-only clusters need NAT64/DNS64 for pods to reach IPv4-only endpoints.
- On dual-stack clusters, set `ipFamilyPolicy: PreferDualStack` to expose the Services
  on both families.
- On IPv6-only or IPv6-primary clusters, do not roll back to an older ZTWA version.
  Older images listen on IPv4 only and fail readiness.
